# University of Claude

**MS in Computer Science — Graphics & Game Engines track.**
A complete graduate curriculum with original lecture materials, mapped onto free university courseware.

Not an accredited institution. No degree, transcript, or credential is awarded.
Everything written for this program is original and free to copy, adapt, and redistribute.
External courses are linked, never reproduced, and remain under their own licences.

---

## Start here

1. **[Program Handbook](00_Program/UC-MSCS-Program-Handbook.pdf)** — the degree: structure, prerequisites, four-semester sequence, assessment standard.
2. **[Continuation Record](00_Program/UC-Continuation-Record.pdf)** — Semesters 5–12: the twenty-four post-degree courses, and what each semester's three courses converge on.
3. **[Free-Resource Catalog](00_Program/Free-Resource-Catalog.pdf)** — all 84 courses mapped to 268 free resources.
4. **Any completed course below** — start with its syllabus, then work the modules in order.

Or run the study app, which indexes everything built, tracks which modules you have finished, keeps your notes, and opens the decks and lecture notes for you:

```bash
python _app/server.py
```

See [_app/README.md](_app/README.md). It reads whatever is built, so new courses appear without changing the app.

- `Syllabus.pdf` — outcomes, 13-module schedule, two projects, assessment standard

- `Slides/M01…M13.pptx` — one editable deck per module, with speaker notes
- `Notes/M01…M13.pdf` — dense written treatment: derivations, code, exercises, self-check

- `_build/uc.py` — theme and document engine (PPTX + PDF)
- `_build/make_course.py` — generic course builder; takes a content module name
- `_build/make_readme.py` — regenerates this file from whatever has been built
- `_build/content/` — course content, one file per course plus module batches
- `_build/preview.py` — renders any deck or PDF to PNG for review
- `_build/lint_slides.py` — scans every built deck for HTML entities the slide renderer cannot decode
- `_build/lint_markup.py` — scans all course content for unbalanced inline markup, which the renderers catch only by luck
